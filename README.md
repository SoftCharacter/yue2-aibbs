# YuE2 Studio

**AI 音乐创作工作站** —— 一个基于 PySide6 的桌面应用，把音乐生成、扒谱、歌词识别、音乐特征分析等能力集成到一个统一的图形界面中。

输入一段风格描述和歌词，即可生成带人声与伴奏的完整歌曲；也可以上传已有的歌曲，让 AI 重新编曲翻唱。

> 版本：1.0.0 · 平台：Windows · 运行方式：便携免安装

---

## 功能特性

| 模块 | 说明 |
|------|------|
| 🎵 创作歌曲 | 输入风格描述与歌词，YuE2 先写出旋律与和弦乐谱，再合成带人声和伴奏的完整歌曲（48 kHz 立体声） |
| 🎙️ AI 翻唱 | 上传一首已有歌曲，扒出旋律乐谱、整理歌词后选择新风格，按原旋律重新编曲演唱 |
| 🔁 批量生成 | 批量翻唱改词（多音频 → 扒谱 → 识别 → 改词 → 翻唱）；批量创作（主题/歌词 → 写词 → 生成） |
| 🎼 乐谱编辑 | 可视化编辑 ABC 乐谱（改旋律、重配和弦、加独奏），调整风格与歌词后按新乐谱重新生成 |
| 📝 扒谱分析 | SheetSage2 把录音转成可编辑乐谱：旋律（人声/器乐）、和弦、节拍、调性、段落结构，可导出 ABC / MIDI / 标注文件 |
| 🎤 歌词识别 | Qwen3-ASR-1.7B 从人声中识别歌词（30 种语言与 22 种方言），ForcedAligner 逐字打时间戳，自动断句、加段落标签、导出 LRC |
| 🧬 音乐特征 | MERT-v2 提取 1024 维音乐表征（25 帧/秒、24 层），可视化歌曲结构、比较多首歌曲相似度，导出 `.npy` |
| 📚 作品库 | 草稿、未完成任务与成品统一管理；中断的任务可续跑复用已完成阶段，重新解码生成新作品 |
| ⚙️ 设置 | 模型文件状态、设备/显存预算、注意力后端等运行参数 |

## 技术架构

**界面层**：Python + PySide6（Qt），Fusion 风格，自定义 QSS 主题。

**任务层**：单工作线程的任务调度器，长任务在后台执行，通过进度回调驱动界面，支持取消与断点续跑。

**引擎层**：按需加载模型，管理各模型的加载状态与生命周期。

**模型层**（均由 `models/` 目录提供，本地离线运行）：

| 模型 | 用途 | 下载 |
|------|------|------|
| YuE2-3B | 音乐生成（乐谱规划 + 声学合成 + 音频解码） | [Hugging Face](https://huggingface.co/m-a-p/YuE2-3B/tree/main) |
| YuE2-Vae | 音频编解码 | [Hugging Face](https://huggingface.co/m-a-p/YuE2-Vae) |
| SheetSage2 | 音频转谱（扒谱分析） | [Hugging Face](https://huggingface.co/m-a-p/SheetSage2) |
| Qwen3-ASR-1.7B | 人声歌词识别 | [Hugging Face](https://huggingface.co/Qwen/Qwen3-ASR-1.7B) |
| Qwen3-ForcedAligner-0.6B | 歌词逐字时间对齐 | [Hugging Face](https://huggingface.co/Qwen/Qwen3-ForcedAligner-0.6B) |
| MERT-v2-30s | 音乐特征提取（30 秒片段） | [Hugging Face](https://huggingface.co/m-a-p/MERT-v2-30s/tree/main) |
| MERT-v2-FullSong | 音乐特征提取（整曲） | [Hugging Face](https://huggingface.co/m-a-p/MERT-v2-FullSong) |

**乐谱渲染**：abcjs（通过 QtWebEngine）呈现与导出乐谱。

**其他依赖**：PyTorch（CUDA）、ffmpeg（音频解码）。

```

```

## 快速开始

1. 确保 `models/` 目录下已放置所需的模型权重，`env/` 为完整的便携运行环境。
2. 双击 `启动器.bat` 启动应用。
3. 在左侧导航选择功能模块，按页面引导操作。

命令行启动：

```bat
env\python.exe -m app.main
```

## 系统要求

- Windows 10/11（64 位）
- NVIDIA GPU（CUDA），用于 PyTorch 推理
- 显存建议充裕：歌曲时长越长、质量越高，所需显存越大；可在「设置」中调整显存预算与注意力后端以适配不同显卡

## 常用工作流

**创作一首歌**：`创作歌曲` 页 → 填写风格描述与歌词 → 点击生成 → 在 `乐谱编辑` 微调乐谱 → 重新生成。

**翻唱一首歌**：`AI 翻唱` 页 → 上传音频 → 自动扒谱与整理歌词 → 选择目标风格 → 生成。

**提取乐谱/歌词**：`扒谱分析` / `歌词识别` 页 → 上传音频 → 运行 → 导出 ABC、MIDI、LRC 等文件。

**批量生产**：`批量生成` 页 → 配置主题列表或音频列表 → 后台逐条执行，结果统一入作品库。

> AI 写词 / 改词功能依赖在「设置」中配置的 LLM 服务（API 地址、模型与密钥）。

## 输出说明

生成结果默认保存到 `outputs/` 目录（可在设置中更改），按任务类型分目录、以时间戳命名。常见产物包括：

- 音频：`mp3`（比特率可在设置中调整）
- 乐谱：`abc` / `midi` / 标注文件
- 歌词：`lrc`（带时间戳）
- 特征：`npy`（MERT 表征）
